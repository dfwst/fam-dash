rlyfe Privacy Policy

Last updated November 13, 2026

rlyfe is a private, invite-only dashboard used by one family to keep up with their own email. It is not offered to the public. This page explains what rlyfe does with the data it can see.

What rlyfe accesses

  • Gmail, for accounts the owner connects: message headers (sender, subject, date), message text, labels, and Gmail filter settings.
  • Sign-in details for the family members who use rlyfe (email address and a two-step verification factor), managed by Supabase Auth.

How it is used

  • To sort incoming mail into "needs action," "worth a glance," and "junk," and to show a short summary of each item that needs action.
  • To archive or mark as read mail the owner has chosen to clear, and to create Gmail filters the owner approves.
  • To draft replies the owner can review. rlyfe never sends email without the owner's explicit tap.

Where data goes

  • Data is stored in a private Supabase database protected by row-level security and two-step sign-in. Google access tokens are encrypted at rest and are only readable by rlyfe's server functions.
  • To sort and summarize mail, message text is sent to Anthropic's Claude API. Anthropic does not use API data to train its models by default.
  • Data is never sold, shared with advertisers, or used for any purpose other than the features above.

Google API data

rlyfe's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your control

  • Disconnect an account at any time from your Google Account's third-party access page; rlyfe then loses access immediately.
  • On request, all stored data for a disconnected account is deleted.

Contact

Questions: contact the rlyfe owner through the support email shown on Google's sign-in screen.
